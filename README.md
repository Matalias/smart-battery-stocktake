# Smart Battery Physical Stocktake & Reporting System

**Developed by AOxLab**

Version: V2.1.1 UAT Edition

## Project Overview

A web-based stocktake and reporting system designed to simplify physical battery inventory verification and daily stock reporting.

The system compares imported Live Stock records with actual physical stock counts to identify inventory discrepancies.

## Key Features

- CSV and Excel Live Stock import
- Dynamic product and brand records
- Physical stock verification
- Rack, floor and unopened stock calculator
- Stock discrepancy detection
- Defective stock recording
- Remarks and additional notes
- Automatic local draft saving
- Master Excel report export
- Responsive desktop and mobile interface

## Stocktake Workflow

1. Download the latest Live Stock file.
2. Import the file into the system.
3. Perform physical stock counting.
4. Verify stock quantities and discrepancies.
5. Record defective stock and remarks.
6. Save and review the stocktake session.
7. Export the updated Master Excel report.
8. Review and submit the report manually.

## Data Privacy and Storage

The system is designed to process inventory records within the user's browser without requiring a central database.

Users must obtain appropriate authorization before processing confidential company records. Exported reports should be reviewed before official submission.
